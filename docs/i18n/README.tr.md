## ✨ v9.3.0 Yenilikleri

- **20 Dünya Dili + Telefon Diline Göre Otomatik Geçiş**: Bölgeye değil yalnızca telefonun sistem diline göre geçiş yapar; Ayarlar'dan anında değiştirilebilir.
- **Otomatik OTA Güncelleme Penceresi + Sürüm Notları + Çoklu Akış Hızlandırma**: Yeni sürümde uygulama içi güncelleme penceresi ve sürüm notları açılır; en hızlı ayna + 4 paralel HTTP Range akışı ile çok daha hızlı iner (SHA-256 ve imza doğrulaması korunur).
- **Rust Şifreli Ücretsiz DeepSeek V4.1 Flash**: Kurulumsuz kullanıma hazır, sıfır düz metin anahtar, TLS pinning ve BYOK desteği.
- **Wi-Fi kapansa bile bağlı kalan Kablosuz Hata Ayıklama Shell Yardımcısı**.
