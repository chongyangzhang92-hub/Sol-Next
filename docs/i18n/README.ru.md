## ✨ Что нового в v9.3.1

- **20 языков мира + автопереключение строго по языку системы**: Автоматически определяет язык интерфейса телефона (без привязки к региону), доступно мгновенное переключение в Настройках.
- **Автоматическое окно OTA-обновления + список изменений + многопоточное ускорение**: При выходе новой версии появляется диалог с описанием обновлений; загрузка ускорена за счёт выбора быстрого зеркала и 4 параллельных потоков HTTP Range (с проверкой SHA-256 и подписи).
- **Встроенный бесплатный DeepSeek V4.1 Flash в Rust-хранилище**: Работает сразу из коробки, без ключей в открытом виде, с TLS pinning и поддержкой BYOK.
- **Устойчивый Shell-помощник при выключении Wi-Fi**: Стабильный виртуальный экран и HD ИИ-звонки.
- **Возможности Android 16/17**: Generative UI, Magic Cue, AppFunctions, игровое управление 60Hz и локальный брандмауэр приватности.
