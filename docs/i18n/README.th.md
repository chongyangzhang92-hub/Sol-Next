## ✨ มีอะไรใหม่ใน v9.1.1

- **รองรับ 20 ภาษา + เปลี่ยนอัตโนมัติตามภาษาโทรศัพท์**: อิงจากภาษาระบบของโทรศัพท์เท่านั้น (ไม่ขึ้นกับภูมิภาค) และสลับภาษาได้ทันทีในเมนูตั้งค่า
- **ป๊อปอัปอัปเดต OTA อัตโนมัติ + บันทึกเวอร์ชัน + เร่งความเร็วดาวน์โหลดหลายช่องทาง**: แสดงหน้าต่างแจ้งอัปเดตพร้อมรายละเอียดเวอร์ชันใหม่ ดาวน์โหลดเร็วขึ้นด้วย 4 ช่องทาง HTTP Range พร้อมตรวจสอบ SHA-256 และลายเซ็น
- **DeepSeek V4.1 Flash ฟรีในตัว เข้ารหัสด้วย Rust**: ใช้งานได้ทันที ปลอดภัย ไม่มีคีย์แบบข้อความธรรมดา และรองรับ BYOK
- **Wireless Debugging Shell Helper ยังเชื่อมต่อได้แม้ปิด Wi-Fi** รองรับหน้าจอเสมือนเบื้องหลังและ AI โทรศัพท์
