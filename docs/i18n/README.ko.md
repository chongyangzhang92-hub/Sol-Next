## ✨ v9.1.2 주요 업데이트

- **전 세계 20개 언어 지원 & 휴대폰 언어 자동 감지**: 지역이 아닌 휴대폰 시스템 언어에 따라 자동 전환되며(한국어, 영어, 중국어, 일본어, 아랍어 RTL 등), 설정에서 즉시 변경할 수 있습니다.
- **OTA 업데이트 자동 팝업 + 버전 설명 + 멀티스트림 고속 다운로드**: 새 버전 배포 시 앱 내 업데이트 팝업과 변경 내역을 자동 표시하며, 미러 자동 경합 + 4채널 HTTP Range 병렬 다운로드(SHA-256 및 서명 검증 유지)로 속도를 대폭 개선했습니다.
- **Rust 네이티브 암호화 DeepSeek V4.1 Flash 무료 내장**: 별도 설정 없이 바로 사용 가능(평문 키 제로, TLS 피닝), 언제든 OpenAI/Claude/Gemini 등 BYOK 전환 지원.
- **Wi-Fi 종료 후에도 유지되는 무선 디버깅 Shell 도우미**: 백그라운드 가상 화면 및 AI 고음질 통화 연결 유지.
- **Android 16/17 최신 아키텍처**: Generative UI 카드, Magic Cue, AppFunctions, 60Hz 게임 제어, 온디바이스 프라이버시 방화벽.
