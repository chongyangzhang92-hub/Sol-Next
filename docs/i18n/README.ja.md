## ✨ v9.2.0 の新機能

- **世界20言語対応・端末言語への自動切替**：地域ではなくスマートフォンのシステム言語のみに基づき自動切替（日本語・英語・中国語・韓国語・アラビア語 RTL など20言語）。設定から手動切替も瞬時に可能。
- **OTA 自動更新ポップアップ・更新内容表示・マルチストリーム高速ダウンロード**：新バージョン検出時にアプリ内で更新内容付きポップアップを表示。複数ミラー自動競速＋4並列 HTTP Range 分割ダウンロード（SHA-256・署名検証完備）で大幅に高速化。
- **Rust 原生暗号化 DeepSeek V4.1 Flash 無料内蔵**：インストール直後から利用可能。平文キーゼロ・TLS ピニング保護・任意のクラウドモデル BYOK にも対応。
- **Wi-Fi オフでも維持されるワイヤレスデバッグ Shell 助手**：仮想ディスプレイと AI 通話パイプラインが Wi-Fi 切断後も安定稼働。
- **Android 16/17 先進機能実装**：Generative UI カード、Magic Cue、AppFunctions、60Hz ゲーム操作、オンデバイス個人情報保護ファイアウォール。
