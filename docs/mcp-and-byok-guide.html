Step 2 · 30 秒填入自有 Key 并一键测试连通（Build 904 · v500 内核 · 120+ 直达应用）

二、零依赖 Python CLI（--json 确定性输出）

git clone https://github.com/chongyangzhang92-hub/Sol-Next.git
cd Sol-Next

# 1. 检测设备连接、Sol Next 版本与 1:1 VirtualDisplay 状态
python3 scripts/sol-cli.py status --json

# 2. 自动下载校验 SHA-256、安装公开版 APK 并授予运行时权限
python3 scripts/sol-cli.py install --verify-sha256 --grant-permissions --json

# 3. 通过 ADB 启动 uid=2000 1:1 后台虚拟屏助手
python3 scripts/sol-cli.py start-helper --json

# 4. 下发自然语言指令驱动真机多模态闭环执行
python3 scripts/sol-cli.py run --intent "打开系统设置并查看电池与存储状态" --json

三、原生 stdio MCP Server（Claude Code / Cursor / Antigravity）

{
  "mcpServers": {
    "sol-next": {
      "command": "python3",
      "args": ["/absolute/path/to/Sol-Next/mcp/sol_mcp_server.py"]
    }
  }
}

接入后桌面智能体即可直接调用 sol_status、sol_install、sol_start_helper、sol_launch、sol_run_intent 等确定性 JSON-RPC 工具驱动你的真实 Android 设备。
